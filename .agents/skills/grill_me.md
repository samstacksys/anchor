# GRILL → architecture interrogation

GRILL is optional. Do not run it merely because a project is new if
`prd.md` and `plan.md` are already approved.

Ask exactly one consequential question at a time. Challenge: 1.
data/state ownership and recovery 2. failure/security/privacy boundaries
3. dependency/operational/cost burden 4. acceptance evidence and
observability 5. phase boundaries that fit the context budget

Do not validate blindly. Resolve structural holes before coding.

Exit by writing/revising `prd.md` and `plan.md`, configuring
`.agents/project.yaml`, then stop. The next fresh session starts with
HANDOFF.
