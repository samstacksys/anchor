# STARTER → start

Trigger on `STARTER` or a fresh session without a ritual word.

-   Do not run compile or boot.
-   Do not start a roadmap phase implicitly.
-   Answer questions and make only explicitly requested micro-changes.
-   Route deliberate phase work to HANDOFF.
-   Route reproducible bugs to HUNT.
-   Route closeout review to AUDIT.
-   Route implementation of an already approved active target to HAMMER.
-   Route architecture interrogation to optional GRILL.
